# ai-specs

Canonical source of the agent definitions of Katalis Responde Community.

## Contents

- `agents/backend-developer.md` - the server side: route handlers, libSQL, model providers, guards and limits.
- `agents/frontend-developer.md` - the interface: App Router pages, React 19, the shared design system, the panel.
- `agents/product-strategy-analyst.md` - the strategic frame of a story before it becomes a specification.

## Relation with the rest of the repository

- `docs/` holds the standards that apply to every agent: `base-standards.md`, `backend-standards.md`,
  `frontend-standards.md`, `documentation-standards.md`, `security.md`, `development-guide.md`,
  `openspec-tasks-mandatory-steps.md` and `katalis-sdd-standard.md`, which prevails over all of them.
- `.claude/`, `.codex/` and `.cursor/` are generated by `openspec init` and `openspec update`. They are not edited by
  hand.
- The `agents` entry of each of those three folders is a symbolic link to `ai-specs/agents`, so this directory is the
  only place where an agent definition is written.
- The agents here plan. The implementing agent writes the test first, then the code, and leaves its evidence in
  `openspec/changes/<change>/reports/`.

## Rules

- English only.
- No private repository, no client, no price and no key is ever named here.
- A plan that leaves an open decision ("if applicable", "or", "may") is not a plan.
