# Step 10.3 · The sync resolves the real path of every folder it deletes or writes

Task of `tasks.md`: "The sync of decision 9".

The code this report verifies is `191343f` ("Resolve the real path of every folder the sync deletes or writes"), the
commit of the sync. The junction case of `tests/agent-copies.test.ts` was red on `518a117` (step 10.1) and is green
here.

## What changed

`scripts/sync-agents.mjs`:

- `realPath(target)` resolves the real path of the deepest folder of the target that exists and appends the names that
  do not exist yet, so a junction or a symbolic link anywhere in the way is resolved instead of followed.
- `insideRoot(root, target)` compares that real path with `realpathSync(root)`; the sync throws
  `${copy} falls outside ${root}` before it deletes or writes anything, exactly as it did for a lexical path.

The guard of the source stays where it was (`carries no ai-specs/agents folder`, `has no file to copy`), and the sync
still writes the three folders from the source. One assertion of the junction case now asks for
`.claude/agents falls outside`, the string the script writes: on `518a117` the same case failed because the sync
returned no failure at all, which is what the report of step 10.1 records.
