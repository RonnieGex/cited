## 9.1 `docs/search.md` and `.env.example`

**`docs/search.md`** (new, English, UTF-8 with LF) covers what task 9.1 demands, in nine sections:

1. **The store**: libSQL, why the spike chose it, the two findings of the spike that shaped the SQL, one file that is
   backed up by copying it, and the schema table by table.
2. **Ingestion**: the four types, the magic bytes, the two limits before parsing, the skipped file with its reason,
   and the two commands.
3. **Chunking**: 800 characters with 120 of overlap, paragraph and word boundaries, the heading rule, and the honest
   note that a PDF carries no heading.
4. **Embeddings**: the interface and the three providers with their variables, the message that names the variable
   and never a value, and the local HTTP double the tests use.
5. **Hybrid search**: the two rankings, `k = 60`, the top 50 and the top 8, and the two commands.
6. **The command line**: what each script does with `.env`.
7. **Parser licenses**: `@libsql/client` MIT, `mammoth` BSD-2-Clause, `pdf-parse` Apache-2.0, and the statement that
   no package of the tree is GPL or AGPL.
8. **Measured memory**: the table of the four runs (ingestion 107 MB in 32 ms, each search 71 MB in 5 ms), the method
   (`process.memoryUsage().rss`) and the honest note that the corpus is small and the store grows with the documents
   of a business.
9. **What quality to expect** and **the tests**: the Community edition has no reranker and no measured evaluation; a
   keyword-only match always ranks, a meaning-only match depends on the embeddings model; and the table of the six
   test files.

**`.env.example`** gained the names of the embeddings with empty values, an explanation of each one and the default
of the store:

```
# Embeddings of the knowledge search. EMBEDDINGS_PROVIDER is one of openai, ollama or fake.
# openai is any OpenAI-compatible embeddings API and needs base URL, model and key.
# ollama needs a base URL and a model. fake is deterministic, offline and for tests only.
# EMBEDDINGS_DIMENSIONS is optional; it overrides the default of the chosen provider.
EMBEDDINGS_PROVIDER=
EMBEDDINGS_BASE_URL=
EMBEDDINGS_API_KEY=
EMBEDDINGS_DIMENSIONS=

# Database. A local file, or Turso in the cloud with the same code.
# DATABASE_URL is the local file (default .data/katalis.sqlite). TURSO_DATABASE_URL wins over it.
DATABASE_URL=
TURSO_DATABASE_URL=
TURSO_AUTH_TOKEN=
```

The file already carried `EMBEDDING_MODEL` and `EMBEDDING_API_KEY` (singular) for the chat model selection of a later
change; those lines were left exactly as they were, and the new names are the plural ones the design fixes
(`EMBEDDINGS_MODEL`, `EMBEDDINGS_API_KEY`, `EMBEDDINGS_BASE_URL`). `.env.example` was **not opened as a secret file**:
its content is the tracked template with empty values, which the task asks to update.
