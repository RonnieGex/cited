`voice_agent rows=0`: the installation has no voice) and the server was started on a free port with the panel
configured and no voice. `DATABASE_URL` was composed from the worktree with `Join-Path`, so no absolute path of this
machine is written here; the rest of the environment is the one of the step:

The body of the sign-in carries an accent (`ñ` in the password), so it travelled as a UTF-8 file without BOM written
with `[IO.File]::WriteAllText($path, $text, [Text.UTF8Encoding]::new($false))` (first byte `123`, no BOM) and sent with
`curl.exe --data-binary`, which is the rule of the round for an accented body on Windows.

## The sign-in

```
$ curl.exe -s -i -X POST http://127.0.0.1:3215/api/admin/login \
    -H "content-type: application/json" -H "origin: http://127.0.0.1:3215" \
    --data-binary "@.data/login.json" -c .data/step-6-cookies.txt
HTTP/1.1 200 OK
```

## The log of the server, and "For the installer"

Two presses of the button, and the names of the variables that are missing reach the log of the server exactly once:

```
$ Select-String -Path .data/step-6-server.log -Pattern 'ELEVENLABS_API_KEY|VOICE_TOOL_SECRET'
the voice agent is not configured: the environment of the server is missing ELEVENLABS_API_KEY, VOICE_TOOL_SECRET

$ occurrences of 'the voice agent is not configured': 1
$ occurrences of ELEVENLABS_API_KEY in the log: 1
$ occurrences of VOICE_TOOL_SECRET in the log: 1
```

(PowerShell wrapped that line at the width of its console and decorated it as `NativeCommandError` because the server
writes it to stderr: it is one `console.error` of the helper `writeOnce()` of `lib/admin/guard.ts`.)

And the page of whoever installs is still the one that names them, which is what the requirement asks for:

```
$ curl.exe -s http://127.0.0.1:3215/admin -b .data/step-6-cookies.txt -o .data/step-6-admin.html -w "admin status=%{http_code}\n"
admin status=200
installer names ELEVENLABS_API_KEY : True
installer names ELEVENLABS_AGENT_ID : True
installer names VOICE_TOOL_SECRET : True
installer names DAILY_VOICE_MINUTE_LIMIT : True
```

The server was stopped at the end of the verification (`Get-NetTCPConnection -State Listen -LocalPort 3215` answers
nothing) and no other service of this machine was touched.
