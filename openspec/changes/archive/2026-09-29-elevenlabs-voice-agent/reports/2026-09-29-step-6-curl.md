
The build is the production one of step 5 (`npm run build` after `npm run verify:no-test-sdk`), the corpus is the
sample folder of the repository, and the two providers are the deterministic ones: no request of this step leaves the
machine, and `ELEVENLABS_API_KEY` is empty on purpose, which is the case the last check proves.

The bodies of the questions travel in UTF-8 files (`--data-binary "@file"`) because the command line of Windows
mangles the accents of a JSON string, and the playbook records that trap: an accented body sent as an argument arrives
as mojibake and the route answers `400 the body is not valid JSON`.

## What each line proves

- **1 and 2**: without the Bearer and with a wrong one the tool answers `401` and nothing else. The route compares the
  secret in constant time before it reads the body, so an unauthorized caller is never parsed.
- **3**: with the Bearer of the installation the tool answers `200` in `text/plain`, with the answer of the pipeline
  and the sources as the agent has to read them and copy them into `mostrar_fuentes`. The fake provider answers, which
  is what the task asks: no model provider of production is called. The citation carries a relative url, which is what
  keeps a chip of the panel inside this site.
- **4**: the follow-up of the same `conversation_id` is answered inside the same thread, and the store shows the two
  turns of `conv_curl_1` in order.
- **5**: the third question opens `conv_curl_2`, finds nothing in the documents and is refused in words with
  `sources: none`: the agent is told there is no answer instead of being given one to invent, and the store keeps no
  turn of a refusal, which is why only two rows appear in 7.
- **6**: without `ELEVENLABS_API_KEY` the signed URL answers `503` naming the variable and never a value.
- **8**: the day holds no minute, because the route reserves them only for a session it can really hand out: an
  installation without a key never spends the cap.

## Verdict

Task 6.1 is done: the four endpoints answer what the spec says over a real server and real `curl.exe`, the thread of a
call is one thread, a question the documents do not answer is refused and not invented, and the browser-facing route
names the missing variable when ElevenLabs is not configured.
