### The two defects the captures found

Nothing about them is hidden: the captures were read after they were written, and both were corrected before the
report.

- The first run of the script drove a server built by `npm run build` instead of `npm run build:e2e`. The production
  build carries the real package, so the session would have opened a socket to ElevenLabs with a signed URL that is not
  one. The script now says in its header which build it needs, and the run was repeated over `npm run build:e2e`.
- The first run also failed on the microphone, before the state was reached. The script now prints the state and the
  error line instead of only the timeout, which is how the second failure would have been read as well.
