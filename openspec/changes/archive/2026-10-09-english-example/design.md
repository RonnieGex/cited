## Authentic quotation and typography

The no-em-dash rule applies to authored copy, including captions, limits, documentation, labels and report prose. Captured model events, canonical raw transcripts and their faithful quoted display retain the exact captured punctuation, including U+2014. This is a quotation boundary required by the unchanged-evidence contract, not permission to introduce that character in authored copy. Do not sanitize, translate, replace punctuation in, or rerun authentic model output to make a typography test pass. The complete batch remains exactly the three already authorized questions.

For the landing, the no-em-dash assertion inspects authored markup with the agent transcript subtree excluded. A separate transcript-equality assertion includes the whole decoded transcript and checks it against the captured events, preserving U+2014. For README graphics, excerpt-equality assertions likewise compare the complete quoted first paragraph and source text; typography guards inspect authored labels/copy separately. Browser layout measurements use the actual full answer paragraph, including its captured punctuation. Existing line wrapping, canvas, clearance, overflow and column-end constraints remain in force; no truncation or textual shortening is authorized.
