# HTTP validation

Executed `curl.exe --fail --silent --show-error --output NUL --write-out "<url> %{http_code} %{content_type}\n" <url>` for each URL below. Every request returned exit 0. Landing was served by `node tools/serve.mjs` on localhost:4173. Graphics were served by `python -m http.server 4188 --bind 127.0.0.1 --directory <workspace>`.

```text
http://127.0.0.1:4188/community-brand-logos/docs/images/agents-dark.png 200 image/png
http://127.0.0.1:4188/community-brand-logos/docs/images/agents-light.png 200 image/png
```
