### One expectation of the end to end corrected while making it green

The first green run read the colour of the focus outline 0 ms after focusing the button and got
`rgb(247, 252, 219)`, a lime halfway to paper. The button carries `transition-colors` with the curve of the system
(400 ms) and `transition-colors` includes `outline-color`, so the measurement was reading a colour in flight. The test
waits 600 ms now, with the reason written in it. The outline is `rgb(221, 244, 105)` once it lands.

## The captures

`scripts/render-delivery-captures.mjs` is new and committed: it is the only tool of these captures, so anyone can
render them again.

```
$ npm run build && npm run start -- --port 3200
$ node scripts/render-delivery-captures.mjs <katalis-dev/tasks/capturas-community-04> http://127.0.0.1:3200
rendered kit-1440.png (1440px wide)
rendered kit-375.png (375px wide)
rendered readme-primera-pantalla-light.png
rendered readme-pie-light.png
rendered readme-primera-pantalla-dark.png
rendered readme-pie-dark.png
```

The kit is a screenshot of the application `npm run start` serves. The README is not a screenshot of an editor: the
script posts `README.md` to the Markdown API of GitHub (`https://api.github.com/markdown`, `mode: gfm`,
`context: RonnieGex/cited`), writes the HTML GitHub answered at the root of the worktree so that its relative image
addresses point at the files of this repository, and reads it as a `file://` address in Chromium, once with
`colorScheme: light` and once with `dark`. The only thing the script adds is the ground of each colour scheme and
`img { max-width: 100% }`; the `height="48"` of the flame is the attribute of the README and nothing else sizes it.
