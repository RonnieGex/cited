## 6.4 `/api/ask` from the flow of the page

The page posts `{"question": string, "sessionId": string}` with `content-type: application/json`. On this machine the
inline form of `curl.exe` does not survive the argument passing of PowerShell (the quotes arrive escaped and the route
answers `the body is not valid JSON`), so the body travels in a UTF-8 file and the command is the one below; the
conclusion is the same one the browser gets.

```powershell
$path = Join-Path $env:TEMP "community-08-ask.json"
[IO.File]::WriteAllText($path, '{"question":"¿Cuánto cuesta la afinación de una bicicleta?","sessionId":"curl-tab-1"}', [Text.UTF8Encoding]::new($false))
curl.exe -sS -X POST http://127.0.0.1:3200/api/ask -H "content-type: application/json" --data-binary "@$path"
```
