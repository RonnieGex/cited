### `ALLOWED_ORIGINS`

Its row in the configuration table of both READMEs was `no` ("planned in `admin-and-public-ui`") and is now `yes`. The
test that compares the table with the code looks for the variables under `lib/`, `scripts/` or `app/`, and the variable
was read in `proxy.ts`, at the root, so reading it moved into `lib/headers/csp.ts` as `policyFor({ pathname,
environment, development, nonce })`, which the proxy calls. It is the same policy as before, with a unit test of its
own.

from this change on, so the word left the list, exactly as `answer` did in `pluggable-models-and-ask`. What still needs
a tag is a capability the table marks `Planned`: the voice agent, the administration panel, the shared design system,
the hardening and the deploy.
