## 9.1 `docs/widget.md`, the README rows and the capture of the chat

### `docs/widget.md`

The document has six sections: the snippet the owner pastes, `ALLOWED_ORIGINS` with the normalization and the safe
default of an empty list, the `Content-Security-Policy` of `/` and `/embed` with the nonce and the `frame-ancestors`,
the `sessionId` of the tab, the language, and how to build and test the file (`npm run build:widget`, the 5 KB ceiling,
`tests/widget.test.ts` and `e2e/widget.spec.ts`).

### The status rows

`scripts/readme-graphics/data.mjs` is the single source of the table (the README and the graphic follow it). The row
that put the panel and the public face together became two:

| Before | After |
| --- | --- |
| `Admin panel, public page and widget in Spanish and English` | `Public chat of the business, with the widget any site can embed` / `Admin panel and onboarding in Spanish and English` |
| `Planned` / `admin-and-public-ui` | `Available` / `openspec/specs/public-chat/spec.md`, and `Planned` / `admin-and-public-ui` |

The row marked `Available` links the delta spec of the open change, which is what the scenario "Available means
specified and merged" allows while the change is open: the file of `openspec/specs/public-chat/spec.md` appears when
the change is archived and is never written by hand.

### `ALLOWED_ORIGINS`

Its row in the configuration table of both READMEs was `no` ("planned in `admin-and-public-ui`") and is now `yes`. The
test that compares the table with the code looks for the variables under `lib/`, `scripts/` or `app/`, and the variable
was read in `proxy.ts`, at the root, so reading it moved into `lib/headers/csp.ts` as `policyFor({ pathname,
environment, development, nonce })`, which the proxy calls. It is the same policy as before, with a unit test of its
own.

### The honesty guard

`scripts/readme-graphics/honesty.mjs` listed `widget` among the words that need a `Next` tag. The widget is available
from this change on, so the word left the list, exactly as `answer` did in `pluggable-models-and-ask`. What still needs
a tag is a capability the table marks `Planned`: the voice agent, the administration panel, the shared design system,
the hardening and the deploy.

### The real capture of the chat

`docs/images/chat-page.png` is not drawn: it is a real capture of `/` with a question answered and the citation open.

```powershell
node scripts/render-readme-captures.mjs http://127.0.0.1:3200
```

```text
wrote docs/images/chat-page.png (44708 bytes)
```

The new script needs the application served by `npm run start` with the corpus of `samples/` and the deterministic
providers, asks the question, opens the citation and writes the file. `README.md` and `README.es.md` show it in `See it
work` with an alt that names what it carries. Its mean luminance is 0.982, so it is one of the light canvases the test
measures, and it has no dark variant because the public chat is painted on the paper of the brand.

assertion was removed or relaxed.
