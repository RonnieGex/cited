## 13.2 — the cut of decision 22

Decision 22: "`cut()` takes the last space or line break before the cut
(`Math.max(head.lastIndexOf(" "), head.lastIndexOf("\n"))`), so a passage cut at a list join is cut where `86b250f`
cuts it." The whole change of `lib/ingest/chunk.ts`:

```diff
   const cut = (text: string, at: number): { head: string; tail: string } => {
     const head = text.slice(0, at);
-    const boundary = head.lastIndexOf(" ");
+    const boundary = Math.max(head.lastIndexOf(" "), head.lastIndexOf("\n"));
 
     if (boundary > at / 2) {
       return { head: head.slice(0, boundary), tail: text.slice(boundary) };
```

The `tail` that starts with the `\n` is trimmed by the `tail.replace(/^\s+/, "")` the two callers of `cut()` already
had, so no other line changes.
